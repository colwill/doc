Anything no repository shows, such as the language it is written in or the database it uses, can be named in its metadata in the Catalogue, as Backstage's end-of-life plugin reads it:

kind: Service
name: ledger
metadata:
  endoflife.date/products: nodejs@20,postgresql@16,ubuntu@22.04

Use endoflife.date's name for each product, and the version after @: 20.11.1 is matched to Node.js 20. A product of your own can point endoflife.date/url-location at a JSON file of its releases, from a host the Settings page lists.
