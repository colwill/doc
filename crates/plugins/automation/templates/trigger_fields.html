{%- if kind == "cron" %}
Cron, five fields, in UTC, such as 0 9 * * 1 for nine every Monday. Start typing, or words such as weekday, to choose a common one.
{%- else if kind == "event" %}
An Event Bus topic, such as plugin.kb.document.imported. Start typing and choose one of the topics this platform publishes; * stands for one part and a final > for the rest.
{%- else if kind == "queue" %}
A Service Bus queue plugins send to, as plugin.automation, discovery/queues/<queue>. Start typing and choose one a plugin has sent to or an automation listens on, or name a new one.
{%- else %}

It gets its own URL and secret once it is saved. Anything that signs a POST's body with the secret, as x-doc-signature: sha256=<HMAC-SHA256>, triggers it. GitHub's x-hub-signature-256 works too.

{%- endif %}
