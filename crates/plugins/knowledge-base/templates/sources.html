Where each space's pages come from. A source syncs when asked, or on its own schedule, which is checked every minute. Each is a DocumentationSource in the catalogue, connected to the repository it reads and to every page it brings in. Credentials are only named here: add one on the plugin's Settings page, or set it as DOC_KB_CREDENTIAL_<NAME>.

With Documentation from repositories on, every repository the platform knows has a source here, kept in step for you and read again whenever the repository is pushed to. The Markdown in a repository — wherever it sits — is documentation in DOC.
